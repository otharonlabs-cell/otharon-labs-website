OTHARON Labs — site vitrine statique

Fichiers :
- index.html : contenu et structure
- style.css : design responsive
- script.js : menu mobile, année et formulaire mailto

Publication rapide : créer un dépôt GitHub public, téléverser les 3 fichiers à la racine,
puis activer Settings > Pages > Deploy from a branch > main > /(root).
Le formulaire ouvre l'application e-mail du visiteur ; il ne stocke pas les messages sur un serveur.
Remplacer l'adresse e-mail dans index.html et script.js si nécessaire.
